# 呼鈴（yobirin）

macOS の自作ランチャー。Raycast の置き換え。メニューバー常駐（Dock に出ない）。

最初の検索欄（既定 ⌘Space）から、アプリ・Chrome のブックマーク・スクリプト・スニペット・組み込みコマンドをまとめて探せます。ほかにウィンドウ整理とクリップボード履歴があります。

## 使い方

| 操作 | キー |
|---|---|
| 開く／閉じる | ⌘Space（設定で変更可）。Esc か、パネルの外をクリックでも閉じる |
| 選ぶ | ↑ ↓ |
| 実行 | Enter（日本語の変換中の Enter は変換の確定にだけ使う） |
| 引数を入れる | 引数のあるスクリプトを選んで Tab か Enter → 入力して Enter |
| 戻る | 引数入力・出力表示中の Esc |
| 設定を開く | ⌘,（検索欄が開いているときだけ。他アプリの ⌘, は奪わない・変換中は効かない） |
| 除外する | 選んだ項目で ⌘⌫（アプリ・設定項目・ブックマーク・スクリプト・スニペットが対象。組み込みコマンドとクリップボード履歴は対象外） |

開いた瞬間に入力ソースを英字（ABC）へ切り替えます。

### 検索欄に出るもの

- **アプリ**: `/Applications`・`/System/Applications`・`~/Applications`（Utilities などのサブフォルダも）。日本語名とファイル名のどちらでも当たります
- **Chrome ブックマーク**: Default プロフィールの `Bookmarks` を読みます。更新されたら次に開いたとき読み直します。開くときも Default プロフィールの Chrome で開きます
- **スクリプト**: スクリプトフォルダ（既定 `~/.config/yobirin/scripts/`・無ければ作ります）にある実行可能ファイル。Raycast のスクリプトコマンド書式のヘッダを読みます
- **スニペット**: `~/.config/yobirin/snippets.json`
- **システム設定の項目**: 「ディスプレイ」「display」「サウンド」「wifi」などで該当の画面が出て、Enter でその画面を開きます。この Mac の `/System/Library/ExtensionKit/Extensions/*.appex` のうち `EXExtensionPointIdentifier` が `com.apple.Settings.extension.ui` のもの（約 50 件）を、日本語名・英語名（`InfoPlist.loctable` と Info.plist）で当てます。`x-apple.systempreferences:<bundle id>` を開きます。`~/Library/PreferencePanes`・`/Library/PreferencePanes` のサードパーティの prefPane も拾い、システム設定に渡して開きます。起動時と「呼鈴を再読込」で読み直します。id は `settings:<bundle id>`（⌘⌫ で除外可）
- **組み込みコマンド**: 呼鈴の設定・呼鈴を再読込・呼鈴を終了・クリップボード履歴・スニペット一覧・左半分・右半分・最大化

### 検索結果から除外

使わないアプリやブックマークは、選んで ⌘⌫ を押すと一覧から消え、「除外しました: 名前」と出ます（日本語の変換中は効きません）。最初の検索欄にもスニペット一覧にも出なくなります。除外した項目は `config.json` の `excluded` に id（`app:<パス>`・`settings:<bundle id>`・`bookmark:<URL>`・`script:<パス>`・`snippet:<名前>`）で残り、設定画面の「除外した項目」から 1 件ずつ「戻す」で復活できます。

並び順は、文字の当たり具合（先頭一致 ＞ 単語の頭 ＞ 部分一致 ＞ 飛び飛び）に、選んだ回数と最近さを足して決めます。空欄のときは使ったことがあるものを出します。

### スクリプト

```bash
#!/bin/bash
# @raycast.schemaVersion 1
# @raycast.title あいさつ
# @raycast.mode compact          # fullOutput / compact / silent / inline
# @raycast.packageName 例
# @raycast.icon 👋
# @raycast.argument1 { "type": "text", "placeholder": "名前" }
# @raycast.description 名前にあいさつする

echo "こんにちは、$1"
```

- `chmod +x` を付けて置けば、次に開いたときから出ます
- `fullOutput`: 出力をパネルに表示。`compact`・`silent`・`inline`: 実行するとパネルを閉じ、出力の最終行を小さな通知で一瞬出します
- PATH に `/opt/homebrew/bin` などを足して、スクリプトのフォルダで実行します

### スニペット

```json
[
  { "name": "住所", "text": "..." },
  { "name": "署名", "text": "よろしくお願いします。\n山内" }
]
```

設定画面の「スニペット」で追加・編集・削除できます（左に名前の一覧、右に名前と本文。本文は改行可）。入力が止まって 0.5 秒後に `snippets.json` へ自動保存し、検索欄・スニペット一覧にすぐ反映します。名前が空・重複（id が `snippet:<名前>` のため）のあいだは保存せず、警告を出します。ファイルを外から書き換えた場合は、設定画面を開き直す・「再読込」・（未編集なら）2 秒ごとの監視で反映します。保存時にファイルが読み込み後に変わっていたら、上書きせず読み直します（そのとき直前の編集は反映されません）。「スニペットを開く」でファイルも直接開けます。

選ぶと元のアプリに貼ります（クリップボードに入れて ⌘V を送り、元のクリップボードの中身は戻します）。スニペット専用のキーは設定で登録します（既定なし）。打つと勝手に展開される仕組みはありません。

### クリップボード履歴

- 0.5 秒ごとに見て、文字と画像を `~/Library/Application Support/yobirin/clipboard/` に残します（メタは `history.json`、画像は `images/`）
- 1Password などが付ける `org.nspasteboard.ConcealedType`・`TransientType`・`AutoGeneratedType` の付いたものは残しません
- 30 日を過ぎたものは、起動時と 1 日 1 回消します
- 専用キー（設定で登録）か、検索欄の「クリップボード履歴」で一覧を開き、選ぶと貼ります

### ウィンドウ整理

左半分・右半分・最大化。最前面のウィンドウを、そのウィンドウがある画面の使える範囲（メニューバー・Dock を除く）に合わせます。同じ方向を続けて実行すると幅が 1/2 → 2/3 → 1/3 → 1/2… と回ります（間にウィンドウを動かしたら 1/2 からやり直し）。キーは設定で登録します（既定なし）。

### 設定

`~/.config/yobirin/config.json`。設定画面（メニューバーのベル → 設定…）からも、ファイルを直接書き換えても反映されます（2 秒ごとに変化を見ています。「再読込」でもすぐ反映）。

```json
{
  "hotkeys": {
    "launcher": { "keyCode": 49, "modifiers": 256 }
  },
  "launchAtLogin": true,
  "scriptsFolder": "~/.config/yobirin/scripts",
  "excluded": ["app:/Applications/Chess.app"]
}
```

`hotkeys` のキーは `launcher`・`snippets`・`clipboard`・`windowLeft`・`windowRight`・`windowMaximize`。`modifiers` は Carbon の値の和（⌘=256・⇧=512・⌥=2048・⌃=4096）。設定画面では欄を押してからキーを押せば登録できます。

使用履歴（並び順に使う）は `~/Library/Application Support/yobirin/usage.json`。

## 初回だけの手作業

1. **Spotlight の ⌘Space を外す**: システム設定 → キーボード → キーボードショートカット → Spotlight。外さないと ⌘Space が Spotlight に取られます（Raycast を使っていたなら既に外れているはず）
2. **アクセシビリティの許可**: 初回起動で案内が出ます。システム設定 → プライバシーとセキュリティ → アクセシビリティで「呼鈴」をオン。ウィンドウ整理と貼り付けに要ります
3. Raycast を使っているなら終了してから、設定画面でキーを押して登録する

## ビルド

要るもの: Xcode、XcodeGen（`brew install xcodegen`）、キーチェーンの Apple Development 証明書。

```bash
make build     # Release ビルド（build/Build/Products/Release/Yobirin.app）
make install   # ~/Applications/呼鈴.app へ入れて起動
make test      # ユニットテスト
make clean
```

- `yobirin.xcodeproj` は `project.yml` から作る生成物なのでコミットしていません（各ターゲットが先に `xcodegen generate` を呼びます）
- **署名は毎回同じ Apple Development 証明書**で行います。アクセシビリティの許可は署名が変わると外れるため、ad-hoc 署名にはしません。テストだけは ad-hoc で回します
- App Sandbox はオフ（アクセシビリティと他アプリのファイル読み取りに要るため）
- ログイン時に起動（`SMAppService`）は、`/Applications` か `~/Applications` に入っているときだけ登録します

## 構成

- `Core/`（YobirinCore.framework）: 画面に依存しないロジック。あいまい一致と並び順・Raycast ヘッダのパース・ウィンドウ枠の計算・ブックマーク JSON・システム設定の項目の読み取り・クリップボード履歴の保存・設定
- `App/`: メニューバー・パネル（SwiftUI＋AppKit）・Carbon ホットキー・入力ソース切り替え・アクセシビリティ・貼り付け・設定画面
- `Tests/`: YobirinCore の XCTest
